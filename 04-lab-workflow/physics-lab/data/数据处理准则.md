## 核心准则（务必逐条遵守，此为课程绪论 PPT 的硬性要求）

### 1 测量的基本概念

- **直接测量**：所要测的量不必经过函数关系计算而直接得到。
- **间接测量**：通过欲测量与直接实测量之间的已知函数关系，经计算间接得到。
- **有效数字**＝（可靠数字，即直读得到的准确数字）＋（一位存疑数字，即估读得到的数字）。有效数字的总位数称为**有效位数**。
- 常见估读约定：游标卡尺**无估读位**；螺旋测微计（千分尺）**需要估读**；读数显微镜可读到毫米的千分位，注意单向读数的方向性。

### 2 误差的定义与分类

- **绝对误差**＝测量值 − 真值；**相对误差**＝(绝对误差 / 真值) × 100%；**标准误差**（标准差 / 均方根差）用于有限次测量。
- 三类误差：

| 误差类型 | 主要来源 | 特点 | 处理 |
|---|---|---|---|
| 系统误差 | 装置本身（装置误差） | 可预知、不可避免 | 见下表 |
| 随机误差（偶然误差） | 环境偶然性 | 无规则涨落、存在统计规律（一般服从正态分布） | 多次测量来减小 |
| 粗大误差（过失误差） | 粗心大意（读错、写错、没调零就用） | 可避免 | 尽量避免、剔除 |

- 系统误差再细分：
  - **已定系统误差**：多次测量与真值的偏离总是相同的那部分（如电表、读数显微镜的零位误差）→ **必须修正**（减去零点修正值 / 零点误差）。
  - **未定系统误差**：已知存在于某个范围但不知具体值（如仪器允差，一般服从均匀分布）→ 用 **B 类不确定度**评估。
- 仪表允差（电工/电子仪表）：`Δ仪 = 量程 × 级别%`。仪表一般分 7 个等级：0.1、0.2、0.5、1.0、1.5、2.5、5.0，数字越小准确等级越高。

### 3 误差分布

- **均匀分布**（仪器允差）：测量值一定落在 `[−a, a]` 区间内。
- **正态分布（高斯分布）**（随机误差）：无穷次测量时均值 μ 可看作真值。区间概率：
  - `[μ−σ, μ+σ]` → 68.3%
  - `[μ−2σ, μ+2σ]` → 95.4%
  - `[μ−3σ, μ+3σ]` → 99.7%
- 随机误差的四条性质：绝对值小的误差出现概率大；正负误差对称等概率；特大误差概率几乎为零；次数非常多时正负误差相互抵消、代数和趋于零。
- **有限次测量的最佳估计**：测量次数有限时，误差不完全服从正态分布，而呈 **t 分布（学生分布）**：n 较小时偏离正态较多，n 较大时趋于标准正态。**本课程测量次数一般取 6 次以上**，在置信概率 68.3% 下可简化认为 t 因子 ≈ 1，即 A 类不确定度直接用「平均值的标准偏差」表示。

### 4 测量结果的完整表达式

统一写为：

> `x = x̄ ± u (单位)`

例：`E = (1.89 ± 0.08) × 10¹¹ N/m²`。
说明：在部分验证性实验中会给出理论真值/约定常数，此时可用绝对误差/相对误差来评估结果。

### 5 直接测量量的不确定度计算（重点，逐条执行）

设对某量进行 n 次等精度独立测量，得到 `x₁, x₂, …, xₙ`。

1. **算术平均值（最佳估计值，须先排除已定系统误差/零点误差）**：

   `x̄ = (1/n) Σ xᵢ`

2. **A 类不确定度**（= 平均值的标准偏差）：

   先求单次测量的标准偏差 `s = √[ Σ(xᵢ − x̄)² / (n − 1) ]`，则

   `u_A = s_x̄ = s / √n = √[ Σ(xᵢ − x̄)² / (n(n − 1)) ]`

   当 `6 ≤ n ≤ 10`、置信概率 68.3% 时，可简化认为 `u_A ≈ s_x̄`。

3. **B 类不确定度**（本课程只评估仪器允差 Δ仪，默认按均匀分布）：

   `u_B = Δ仪 / √3`

   分布类型与系数对照（需要时使用）：

   | 分布类型 | 适用场景 | 系数 |
   |---|---|---|
   | 均匀分布 | 仅知误差界限（游标卡尺、数字仪表分辨力） | √3 |
   | 三角分布 | 误差在界限内中间高、两边低（指针式仪表估读） | √6 |
   | 正态分布 | 校准证书给出置信水平（如 99.7%） | 3 |

4. **总合成不确定度（方和根合成，A、B 分量相互独立）**：

   `u_c = √(u_A² + u_B²)`

5. **给出最终结果**：`x = x̄ ± u_c (单位)`，并按 §3.7 修约对齐位数。

### 6 间接测量量的不确定度（不确定度的传递）

设 `N = f(x₁, x₂, …, x_m)`，各直接测量量 `xᵢ` 相互独立，对应不确定度 `u(xᵢ)`。

- **和差形式（用偏导，合成于绝对不确定度）**：

  `u_c² = Σ[ (∂f/∂xᵢ)² · u(xᵢ)² ]`

- **积商形式（先取对数，用相对不确定度）**：

  `(u_c / N)² = Σ[ (∂ ln f / ∂xᵢ)² · u(xᵢ)² ]`

- **常用函数的不确定度传递公式**：

  | 函数表达式 | 合成不确定度公式 |
  |---|---|
  | `N = x₁ ± x₂` | `u_c² = u(x₁)² + u(x₂)²` |
  | `N = x₁ · x₂` | `(u_c/N)² = (u₁/x₁)² + (u₂/x₂)²` |
  | `N = x₁·x₂ / x₃` | `(u_c/N)² = (u₁/x₁)² + (u₂/x₂)² + (u₃/x₃)²` |
  | `N = k·x`（k 为常数） | `u_c = k·u(x)` |
  | `N = ln x` | `u_c = u(x) / x` |

- 最终结果：`N = N̄ ± u_c (单位)`，其中 `N̄ = f(x̄₁, x̄₂, …)`。
- **扩展不确定度**：`U = k·u_c`（k 为包含因子）。**本课程可不考虑扩展不确定度，只计算合成标准不确定度。**

### 7 有效数字与修约规则（最终结果必须遵守）

- **修约规则：四舍六入五凑偶**（国标 GB/T 8170–2008），不允许连续修约。
  - 示例（取四位有效数字）：
    - 2.717499 → 2.717（舍）
    - 5.165509 → 5.166（入）
    - 4.510500 → 4.510（凑偶，舍）
    - 4.511500 → 4.512（凑偶，入）
    - 4.510501 → 4.511（仅这个修约数最接近，入）
- **有效数字运算规则**：
  - 加减法则：以参与运算各量中**末位（可疑位）最高**的为准。例：`12.4 + 0.571 = 13.0`；`3.11 + 1056.7 + 103 − 9.862 = 1153`。
  - 乘除法则：以**有效数字最少**的数为准。例：`2.7 × 3.902 = 11`；`3600 × 8.0 = 2.9 × 10⁴`。
- **函数运算**：三角函数结果的有效数字与角度的有效数字位数相同（`sin 30.2° = 0.503`）；对数的尾数（小数部分）与真数的有效数字位数相同（`lg 3.27 = 0.514`）；幂运算可用「自变量可疑位上下变动一个单位」来判断结果的可疑位。
- **最终结果位数的确定（步骤固定）**：
  1. **先确定不确定度的有效位数**：最多取两位（通常 1 或 2 位）。规则——
     - ① 看不确定度**首位非零有效数字**：< 3（即 1 或 2）→ 保留 2 位；≥ 3 → 保留 1 位。
     - ② 采用**最大误差限原则（只进不舍）**：欲保留的最低位的后一位数不为 0 则进位，为 0 则舍去。
     - 例：u = 0.12134 → 0.13；u = 0.1201 → 0.12；u = 0.3201 → 0.4；u = 0.3021 → 0.3。
  2. **再修约测量平均值**：使测量值的**末位与不确定度的末位对齐**（平均值按四舍六入五凑偶修约；若平均值需向后补 0 才能对齐，则不确定度只保留 1 位）。
     - 例：`(2.3450 ± 0.0320) cm² → (2.34 ± 0.04) cm²`；`(2.3530 ± 0.0212) cm² → (2.353 ± 0.022) cm²`。
- **其他要点**：
  - 有效数字后面不能随意加 0 或去 0（`980 cm/s² = 9.80 m/s²`，≠ 9.8 m/s²）。
  - 有效数字与单位换算无关（注意科学计数法与十进制的可疑位保持）。
  - 结果较大或太小时用科学计数法表示，如 `(4.56 ± 0.03) × 10⁻⁴ s`。
  - 有效位数反映测量准确度：仪器分度值越细，有效数字多一位，相对误差约减小一个数量级（如钢直尺 ~3.1%、游标卡尺 ~0.31%、螺旋测微计 ~0.06%）。

## 数据处理方法（按实验类型选用）

1. **列表法**：把原始数据整理成表，标注表头、单位、序号，可直观展示各量关系、便于检查数据是否合理。
2. **最小二乘法（线性拟合）**：适用于满足线性关系 `y = a + bx` 的数据。令残差平方和最小，解得
   - `b = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²`，`a = ȳ − b·x̄`
   - 相关系数 `r`，r 越接近 1，说明 x 与 y 的线性关系越好。
3. **逐差法**：适用于等间隔读数。为充分利用数据，把数据分成前后两组，对应相减（相减间距为原临近间距的若干倍），对逐差结果再分别计算 A 类与 B 类不确定度。
4. **作图法**：要求——① 选择合适的坐标范围与分度值；② 标明坐标轴（含物理量与单位）；③ 标出实验数据点；④ 写图名；⑤ 给出必要的图例/图释。可用 Excel 或 Origin 绘图，注意电子表格中的有效位数。
