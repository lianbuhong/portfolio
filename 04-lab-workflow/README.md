# 实验报告 AI 辅助写作工作流

为大学物理实验、电路与模拟电子技术实验两门课程设计的一套**可复现的 AI 协作工作流**：把“写实验报告”拆解为标准化目录、LaTeX 模板、锁定依赖的数据处理环境，以及一套约束 AI 行为的提示词与执行流程，让 AI 在“数据不造假、格式不跑偏、环境可重建”的前提下辅助完成报告。

## 架构分层

| 层 | 文件 | 职责 |
|---|---|---|
| 提示词层 | `Prompt.md` | 定义 AI 的角色、目录职责、任务流程与硬约束（禁止捏造数据、保留模板注释、按章节框架填写） |
| 规范层 | `data/数据处理准则.md` | 将课程的误差理论、不确定度评定与有效数字修约规则结构化，作为 AI 数据处理的硬性依据 |
| 模板层 | `Template/` | 课程定制的 `.cls` 文档类与 `.tex` 模板，含图、表、公式的规范引用示例 |
| 数据处理层 | `src/` | `environment.yml` 锁定的 conda 环境（numpy / scipy / pandas / matplotlib / uncertainties / lmfit），完成拟合与不确定度计算，输出矢量图供 LaTeX 引用 |
| Agent 执行层 | `.agent/workflows/run-python.md` | 规定 AI 运行脚本前的环境检测、用户确认与执行步骤，保证每次操作可审计 |
| 知识参考层 | `Courseware/`、`References/` | 教材课件与优秀报告实例，作为内容来源 |

## 两门课程的差异被显式编码

工作流不是一套模板硬套两门课，而是把课程准则差异写进各自的提示词：

- **大物实验（physics-lab）：** A/B 类不确定度方和根合成，测量一般 6–10 次，按课程修约规则处理；
- **模电实验（circuit-lab）：** 按分布查表取包含因子，计算扩展不确定度（工程惯例 \(k=3\)），测量一般 10–20 次。

## 体现的能力

提示词工程、LaTeX 工程化、conda 环境与依赖管理、流程设计与知识结构化——核心不是“会用 AI”，而是把 AI 组织进一个有约束、可复现的工程流程里。
