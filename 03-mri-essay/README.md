# 课程论文：磁共振技术演进及临床应用

**课程：** 通识课《生物医学工程——智慧医疗的前世今生》

**完整题目：** 从“看见病灶”到“支持决策”：扩散、灌注与功能磁共振的技术演进及临床应用

## 内容概要

论文围绕三类磁共振技术的发展脉络与临床价值展开：

- **扩散磁共振（DWI/DTI）：** 基于水分子扩散运动的成像原理，及其在急性脑梗死早期诊断中的应用；
- **灌注磁共振（PWI）：** 组织血流灌注的评估方法，以及与扩散成像联合判断缺血半暗带；
- **功能磁共振（fMRI）：** 基于血氧水平依赖（BOLD）效应的脑功能定位，及其在神经外科术前规划与脑科学研究中的应用。
