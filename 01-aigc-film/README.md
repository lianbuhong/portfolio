# 《物有语，史长存》AIGC 短片

一个以革命文物为叙事主角的 AI 生成短片：从南湖红船、马灯、军号等六件文物出发，用新中式油画风格的画面串联一段跨越年代的故事。

## 我承担的工作

本项目为小组合作项目，但我个人承担任务较多，完整经历了从想法到成片的全部环节：

1. **剧本与策划：** 撰写多文物串联版视频脚本，确定六幕叙事结构；
2. **分镜设计：** 编写十六宫格分镜脚本，逐镜头设计画面内容与提示词；
3. **视觉生成：** 通过提示词工程生成统一的新中式油画风格画面，并完成六件文物的角色形象设定；
4. **后期制作：** 完成视频剪辑与海报设计；
5. **展示汇报：** 制作项目展示文稿并撰写配套演讲稿。
